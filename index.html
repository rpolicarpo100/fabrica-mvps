# dentro de fabrica/
python3 agente.py --demo        # loop contínuo offline (templates: 4 geradores ativos)
python3 agente.py --once        # uma só iteração
python3 agente.py --status      # ver a fila
ANTHROPIC_API_KEY=sk-... python3 agente.py   # modo LLM (MVPs gerados do zero)

Adiciona novos alvos em fila.json com "status": "pendente" e o agente trata do resto: SPEC → build → smoke test → reparação → registo. Log completo em ESTADO.md.
