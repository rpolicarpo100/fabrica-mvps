# SPEC — DeckScore (`06-deckscore`)
- **Inspiração:** Fundraisly (PH #1 mês jun-2026) / VC Boom — avaliação de pitch
- **Formato:** single-file `index.html`, zero recursos externos, PT-PT
- **Features do MVP:**
  1. Colar texto do pitch → análise por framework de 10 secções (problema→pedido)
  2. Deteção de métricas quantitativas (€, %, múltiplos, contagens)
  3. Medidor de buzzwords ("BS meter") com humor
  4. Score global investor-readiness + barras SVG por secção + veredito
  5. Sugestões concretas por secção ausente/fraca + exportar relatório .md
- **Critérios de aceitação:** smoke.py verde.
