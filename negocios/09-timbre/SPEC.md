# SPEC — Timbre (`09-timbre`)
- **Inspiração:** Goldfish (PH #2 jun-2026) — "conhece o teu trabalho e responde como tu"
- **Formato:** single-file `index.html`, zero recursos externos, PT-PT
- **Features do MVP:**
  1. Colar amostras da tua escrita → análise estilométrica local (formalidade, comprimento de frases, emojis, pontuação, saudação/despedida habituais, palavras-assinatura)
  2. Perfil de voz em chips
  3. Gerador: destinatário + pontos → mensagem no teu tom (saudação do teu estilo, ritmo de frases, emojis se usares, despedida tua)
  4. Copiar resultado + persistência localStorage
- **Critérios de aceitação:** smoke.py verde.
